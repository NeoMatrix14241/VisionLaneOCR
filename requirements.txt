# Python 3.12 or newer is REQUIRED:
#   numpy 2.5 and scipy (via python-doctr) need >= 3.12; torch 2.14, python-doctr 1.1,
#   Pillow 13 and pandas 3 need >= 3.11.
#
#   python -m venv .venv
#   .venv\Scripts\activate
#   python -m pip install --upgrade pip
#   pip install -r requirements.txt            (build tools: pip install -r requirements-dev.txt)
#
# GPU (Windows): the default PyPI torch wheel for Windows is CPU-only. Install the CUDA build FIRST,
# using the exact command from https://pytorch.org/get-started/locally/ , e.g.
#   pip install torch==2.14.1 torchvision==0.29.2 --index-url https://download.pytorch.org/whl/cu128
# (pick the CUDA tag that matches your driver/GPU; CUDA 13 builds drop pre-Turing GPUs such as GTX 10xx),
# then run the pip install -r above (already-satisfied pins are kept).
#
# NOTE: these versions need the code changes listed in docs/modernization.md
# (python-doctr 1.x removed TensorFlow support and doctr.file_utils.is_torch_available;
#  PyPDF2/PdfMerger and ocrmypdf.hocrtransform.HocrTransform no longer exist).
