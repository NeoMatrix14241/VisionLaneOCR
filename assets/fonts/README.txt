DejaVu Sans (DejaVuSans.ttf) - used for the invisible text layer of searchable PDFs when a page contains
characters that the built-in Helvetica cannot encode (Cyrillic, Greek, Vietnamese, ...).
Version as bundled with matplotlib. Licence: see LICENSE_DEJAVU.txt (Bitstream Vera licence; free to redistribute).
It does not cover CJK scripts; those characters appear as "?" in the PDF text layer (HOCR output is unaffected).
